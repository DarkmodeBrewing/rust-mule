Danger Zone

These actions can rescan large directory trees or generate additional KAD publish traffic. Use them intentionally.

  • Reindex Library: rescans configured shared folders and refreshes the local index.
  • Republish Sources: queues fresh source publish traffic for all indexed shared files.
  • Republish Keywords: queues fresh keyword publish traffic for all indexed shared files and may generate significant KAD traffic.
